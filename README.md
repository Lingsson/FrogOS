## Overview

FrogOS is a multi-tool firmware for the Raspberry Pi Pico W.

## Features

### Wi-Fi Tools
- Scan nearby networks
- View RSSI and channel information
- Device network information
- Create access points


### HID / Automation Tools
- 30+ BADUSB payloads
- Includes system interaction, UI automation, and network information display (authorized testing only)


### Mouse Tools
- Virtual mouse
- Mouse jiggler
- Auto clicker
- Scroll spam


### Keyboard Tools
- Virtual keyboard
- Keyboard tester


### password brute force
- Sends predefined password lists (Top 100 / 500 / 1000 / 5000 / 10000) most common passwords from real data breach.


### System Info
- CPU
- Temp
- RAM
- IP


## Hardware

Required:

- Raspberry Pi Pico W
- SSD1306 OLED (128x64)
- 6 push buttons
- Jumper wires
