## Overview

FrogOS is a multi-tool firmware for the Raspberry Pi Pico W.

Features include:

- OLED menu system
- Wi-Fi scanning tools
- USB HID keyboard tools
- Mouse utilities
- Virtual keyboard
- System information
- Hardware navigation using buttons


## Features

### Wi-Fi Tools
- Scan nearby networks
- View RSSI and channel information
- Device network information
- Create access points

### HID Tools
- Keyboard emulation
- Mouse emulation
- Virtual keyboard

### Utilities
- Mouse jiggler
- Auto clicker
- Scroll spam
- System monitor



## Hardware

Required:

- Raspberry Pi Pico W
- SSD1306 OLED (128x64)
- 6 push buttons
- Jumper wires
